# v3.3.6-rc.2 — Show the admin password on the startup line (pre-release)

> 2026-10-03 · release candidate

## Changes

- `start.bat` now displays the admin-password label and effective password on the same startup line, so operators do not have to look it up separately.
- The launcher uses the existing `python-dotenv` configuration loader. If a system environment variable overrides `.env`, it displays the effective value; if unset, it displays the service default, `admin`.
- Includes the WebUI build dependency checks and clearer installation-failure messages from `v3.3.6-rc.1`.
