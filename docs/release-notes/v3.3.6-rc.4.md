# v3.3.6-rc.4 — Unify account-pool configuration (pre-release)

> 2026-10-03 · release candidate

## Changes

- Removed `.env` account fallbacks. Accounts are now configured only through the WebUI account pool or `data/accounts.json`.
- The service no longer reads legacy or indexed `DEEPSEEK_TOKEN`, `DEEPSEEK_COOKIES`, and `DEEPSEEK_EMAIL` variables. Per-account proxy configuration that existed only for the environment-variable fallback was removed as well.
- An empty account pool no longer attempts environment-variable credentials. Startup logs explain how to add an account in the WebUI or `data/accounts.json`.
- Removed the WebUI's read-only environment-account status and source counts. Updated `.env.example`, the English README, and maintainer documentation.
- The service version returned by the admin API is updated to `3.3.6-rc.4`.

## Validation

- Full pytest suite: 103 tests passed.
- WebUI TypeScript checks and Vite production build passed.
