# v3.5.0 — Beginner-friendly docs in both languages

This release is documentation-focused: the project now explains itself in plain language, and Persian is the default page on GitHub. No proxy, protocol, or configuration behavior changed.

## Added

- **Persian is now the default README.** `README.md` is the simple Persian guide, so Persian-speaking visitors land directly on instructions they can follow.
- **Simple English guide** in `README_en.md`, mirroring the Persian guide section for section so both languages stay in sync.
- **No-git installation path** as the primary method: download the ZIP, unzip, open a terminal in the folder, run the installer, then `ds2api`. Cloning with git is documented as an optional second method.
- **Troubleshooting table** covering the common beginner failures: `ds2api` not recognized, panel not loading, account errors, rejected images, missing Python, and missing modules.

## Changed

- **`README_fa.md` is now a short pointer to `README.md`**, so existing links and bookmarks keep working.
- **The detailed English reference moved to `docs/technical-guide-en.md`** instead of being deleted. It keeps the model compatibility notes, the full API reference, session and tool-call behavior, development instructions, and the complete configuration reference. Relative links were updated for the new location.
- **Setup pages were trimmed to what a first-time user needs:** prerequisites, install, opening the panel, adding an account, creating an API key, one test request, three security reminders, a four-row settings table, and uninstall steps.
- **`AGENTS.md`** now states which file is the default guide and where the detailed reference lives.
- **`tools/chromium-credential-capture/README_fa.md`** links to the new main README.

## Compatibility and limitations

- Unchanged: the proxy still uses DeepSeek's private web-chat protocol and still forwards text only. Image and multimodal inputs are rejected with HTTP 400 rather than silently dropped.
- The client model alias remains a local route hint, not an official DeepSeek API model selection guarantee.

## Validation

- Full pytest suite, the application smoke test, and the offline end-to-end checks pass.
- Python compilation passes.
- Every relative Markdown link in the repository was checked and resolves.
