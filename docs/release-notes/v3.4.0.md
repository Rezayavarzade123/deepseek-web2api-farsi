# v3.4.0 — Easier installation, Farsi localization, and continuous chats

This feature release improves installation and day-to-day use while keeping the proxy's private-web-protocol and text-only limitations explicit.

## Added

- **Cross-platform installer and `ds2api` launcher:** installs the complete proxy, adds the launcher to the user's PATH, and supports Windows Command Prompt and PowerShell. The optional Chromium credential-capture helper remains separate from the app installer.
- **Farsi WebUI localization:** adds Persian translations and right-to-left layout, alongside updated English and Persian setup documentation.
- **WebUI startup details:** `ds2api` prints the local WebUI URL and the configured admin password, with a reminder to keep terminal output private. New local installs use `admin`; public binds with that weak default remain blocked.

## Conversation continuity

- The Playground now keeps one upstream DeepSeek chat across turns in a thread; Clear starts a new chat.
- Untagged authenticated API requests reuse a fallback upstream chat per API key and request mode. Explicit conversation IDs take precedence; set `SESSION_CACHE_FALLBACK=none` to require explicit IDs.

> **Session-sharing note:** independent untagged conversations using the same API key can share or disrupt context, especially when requests run concurrently. Use distinct API keys or explicit conversation IDs when conversations must be isolated.

## Compatibility and limitations

- Updates the proxy's default model alias/configuration for the current DeepSeek web-chat experience. The alias is not an official API model selection guarantee.
- The proxy uses DeepSeek's private web-chat protocol, which can change independently, and still forwards text only. Image/multimodal API inputs are rejected rather than silently discarded.
