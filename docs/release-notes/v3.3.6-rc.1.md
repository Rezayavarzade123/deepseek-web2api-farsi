# v3.3.6-rc.1 — WebUI dependency installation fix (pre-release)

> 2026-10-03 · release candidate

## Fixes

- `start.bat` now delegates WebUI dependency installation and builds to a standalone build script.
- Before building, the script verifies that `tsc` and `vite` are available. If dependency installation fails or either tool is still missing, it exits with an explicit error instead of continuing with a partial `node_modules` directory.
- When `package-lock.json` exists, the build script uses `npm ci`. Installation failures now prompt the operator to check npm registry or proxy connectivity.
- The GitHub Release workflow marks tags with a pre-release suffix (for example, `v3.3.6-rc.1`) as pre-releases.

## Validation

- Reviewed the batch-file diff for format and syntax issues.
- The WebUI build was not run: the npm registry proxy was unreachable in the environment, so dependency installation failed. This release candidate improves the error handling for that failure path.
